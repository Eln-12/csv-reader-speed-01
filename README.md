# csv-reader speed entry

Dependency-free ES module parser for the `csv-reader-speed-01-run-20261121` competition.

- `solve.js` exports `run(input)`.
- `main.ts` reads `/input/cases.json` and writes `/output/answers.json`.
- Parser uses a single forward scan with span slicing for unquoted fields and chunked decoding for quoted fields.
